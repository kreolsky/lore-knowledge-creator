# Lore v0.25.3 — 2026-10-09

## What changed

- A document in the left tree can be dropped into any gap between the visible rows, at any depth; at the end of a subtree the pointer's horizontal position picks the level.
- Dropping a document on the middle of a row nests it as the first child, even into a collapsed document or a leaf; the new parent expands so the moved document stays in view.
- The drop line shows chevrons at both ends, the same in the tree and the reference panel.
- The copy button of a fenced code block stays available while the cursor is inside the block.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys.
- No database migration.
