# Lore v0.24.0 — 2026-10-06

## What changed

- **Extractor: `ranges` tables bound to a variable.** A table named after a variable (or a `calculate:` output) whose rows carry attributes produces `<var>_<attr>` template variables — `min`/`max` for numbers, `is: [..]` for enum values, `by:` for per-selector sub-tables. No `calculate:` line is needed; `range()` works as before.
- A malformed bound table now fails the extractor run at setup, and the reason appears in the Pipeline Error note on the source document instead of leaving the marks empty.
- **Multiselect values now join with ", " by default** — "A, B and C" becomes "A, B, C". Set `separator: " and "` on the variable to get the old wording.
- **Phones and tablets:** hover previews no longer open on a tap, row menus open on tap and close on a tap outside, hover-only actions are always visible on touch, inputs no longer trigger iOS zoom, and the chat send button is an icon-only square on narrow screens.
- An additive schema update no longer logs a schema-fingerprint mismatch at ERROR on every startup.

## Upgrading

```sh
docker compose pull
docker compose up -d
```

- No new `.env` keys.
- No database migration.
- Review extractor configs that use multiselect variables if you relied on the "and" before the last item.
