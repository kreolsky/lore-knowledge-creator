# Lore v0.25.5 — 2026-10-13

## v0.25.5

### What changed

- Dark theme: the accent is a deeper iris, so white button text no longer washes out; links, sources, active icons and selected dropdown items use a lighter tint of the same hue.
- Dark theme: sticky notes and your own chat bubbles use the neutral dark surfaces instead of a tinted plaque. The light theme keeps its yellow notes.
- Dark theme: hovering a subtle button now lightens it instead of darkening it.
- Editor, dark theme: palette highlight colours render as deep fills with light text. Documents still store the plain hex; the light theme and custom colours are unchanged.

### Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys.
- No database migration.

## v0.25.4

### What changed

- A message sent while the agent is busy now queues as a chip with ✕ above the composer: it runs as its own turn after the ones before it, survives a page reload and shows in every tab. Images queue too.
- ✕ on a chip removes the message from the queue; Stop hands queued messages (text and images) back to the composer, and works on a turn started in another tab.
- Two quick sends in a row no longer fail the turn or lose its content; two first turns in a fresh project no longer fail with "Agent setup failed".
- The new-chat button shows a back arrow and doubles as the way back to the chat list.
- Admins can hide a model from every chat picker (Admin → Models: Hidden · Private · Public). A hidden model still serves technical calls (prompt refinement, titles, extractor) and sessions pinned to it; the default chat model cannot be hidden. Models & APIs and Model access now sit right after Info.
- A deleted document in a project's Skills folder no longer turns off the shipped skill of the same name.
- Inline code in a heading scales with the heading.
- The user guide is now in English.

### Upgrading


`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys. `TURN_LOCK_*` keys, if you set any, are no longer read.
- Browser tabs open before the upgrade must be reloaded before sending chat messages.
- No database migration.

## v0.25.2

### What changed

- Each branch of an agent chat is now its own session: editing and resending a message, or rewinding to an earlier point, starts a new branch instead of rewriting the current one. The 1/N switcher moves between branches of one conversation, in the same order from every branch.
- The chat list counts a conversation once and previews its active branch; deleting a chat from any branch deletes the whole conversation.
- The first message of a conversation can no longer be edited or rewound to.
- Existing chats with branches are converted on upgrade: every inactive line becomes its own branch, the active line is unchanged. A legacy branch whose branch point cannot be recovered stays readable but refuses new turns.
- An agent edit to a system document (knowledge, rules, skills) that the user approved now applies instead of failing.
- Escape cancels a message edit; in the composer it first discards a voice recording in progress, then stops a running turn.
- Media file buttons: delete on the left, download on the right.

### Upgrading


`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys.
- Migrates the database (chat branches) — back up first, a rollback past this release needs the backup.

## v0.25.1

### What changed

- Generated images can be downloaded and deleted from the chat image preview; a downloaded image is named after its document. Deleting needs full access.
- Deleting the picture of a reference that has no text deletes the reference itself, and the image viewer moves on to the neighbouring image.

## v0.25.0

### What changed

- Agent chat: each step (reasoning, a tool call, an image) reads as a line of the answer and expands into one scrollable box; runs of two or more steps fold under a group header that names what they did.
- A scroll-to-bottom button appears when you scroll the chat up.
- Models your router serves over the Anthropic Messages protocol now work in chat natively, through the same router URL and key; the protocol is picked per model from the router's `/v1/models`. Prompt refinement and extractor nodes still call chat completions, so set their models explicitly if your default model is an Anthropic Messages one.
- Perplexity Search API can be chosen as the agent's web-search provider in admin settings, with a `fast` or `web` mode.
- A turn sent right after the agent service restarts no longer ends with an empty reply row; an agent crash mid-turn closes the turn promptly again.
- A bare-id document link in an agent reply is clickable; text copied from a multi-step reply keeps paragraph breaks.
- Drag-and-drop shows a clear drop line between rows; the go-to-parent button on a reference in the side preview works.
- The backend health check allows 300s on first start, so a slow disk no longer fails `docker compose up`.

### Upgrading


`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys. The Perplexity key and mode are set in admin settings.
- No database migration.
