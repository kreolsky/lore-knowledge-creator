# Lore v0.29.0 — 2026-10-22

## What changed

- Projects can be opened to a whole group. A project now carries one list of audiences — all logged-in users, a moderator's group or an admin group — each with its own access level; a member's effective access is the highest of their own row and every matching audience.
- An owner in a group sets the level for their own group; an admin edits the full list. Making a project public to all users is now admin-only.
- Owners in a group invite from the group's roster through one filterable picker; the picker hides people already in the project and disables levels the group already grants. A member row below the group's level shows the level that actually applies.
- Access changes reach open documents immediately; revoking access in one project no longer closes the user's documents in another.
- Chat: a prompt rail on the right edge lists all your prompts and jumps to any of them; it replaces the "previous message" button.
- Web search can go through your AI router (provider `router`, Anthropic Messages with the native web search tool); `WEB_SEARCH_MODEL` picks the model and defaults to the chat model. Fixed: search providers could fail with "the credentials service is not composed".
- Optional bundled LLM router: set `COMPOSE_PROFILES=router` and configure it under `router/config/` (examples in `router/config.example/`). Without the profile nothing changes. See `self-hosting.md`.
- Admin: the user edit panel stays open after Save with a "Saved" mark; the project "Add user" picker is filterable.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- New optional `.env` keys: `COMPOSE_PROFILES=router` (bundled router, off by default), `WEB_SEARCH_MODEL` (only for the `router` search provider; defaults to the chat model). No keys removed.
- Access change: a public project owned by a non-admin becomes readable by the owner's group only (or private if the owner has no group). Admin-owned public projects stay public.
- This release migrates the database — back up first, a rollback past this release needs the backup (the old `is_public` / group audience fields are removed).
