# Lore v0.38

## Upgrading from 0.37 or earlier

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

Required:

- Migrates the database (v0.38.0) — back up first; a rollback past this release needs the backup.

Optional:

- Tune the long-chat suggestion in the admin panel (search → Chats): `CONTEXT_NUDGE_FLOOR_TOKENS`, `CONTEXT_NUDGE_PERCENTS`.

0.38 needs no new `.env` key and no compose change.

Coming from an older minor: read its note in this folder too, and follow every migration and required step.

## What changed

### v0.38.2

- Chat mode works on a phone: chat list in the left drawer, chat in the center, the document as a full-screen right panel opened by a link tap.
- A search field over the chat list filters by title and adds content matches from two characters.
- The chat-mode composer opens at its minimum height and remembers a dragged height.
- Docs mode and chat mode each remember whether the left panel is pinned.

### v0.38.1

- A new chat started in chat mode with a document open belongs to that document; with nothing open it stays project-level.
- Chat mode and document mode each remember their own text width (Ctrl+Alt+[ / ]).

### v0.38.0

- Chat mode: a new "Chats" tab turns the project page into chat list · chat · document. Chats started there belong to the project, not to a document. The document panel follows what the agent writes; pin it to stop.
- Cmd+K in the chat composer inserts a document link.
- A long chat suggests starting a fresh one at up to three thresholds (20/25/30% of the model's window by default); your answer is remembered per chat.
- Projects with no personas get an unselected "Memory Brain" persona.
- The agent can switch one of your chats to another persona and export a chat as JSON into your sandbox.
- A table the agent appends after a code block now becomes a real table.
- The prompt-cache figure beside the token gauge is gone.
