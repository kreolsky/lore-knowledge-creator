# Lore v0.28.1 — 2026-10-20

## What changed

- Editing a document you have edited before no longer writes a false database ERROR (`CREATE document_history … already contains`) to the backend log. The document history itself is unchanged.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys.
- No database migration.
