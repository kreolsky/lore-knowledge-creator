# Lore v0.32.5 — 2026-11-03

## What changed

- An HTML page downloads as a single `.html` file with its source verbatim, instead of pdf/docx/md that produced a broken file. A Download button sits in the page toolbar next to the source toggle.
- A voice note recorded on an open HTML page is saved instead of failing on every reload.
- Members can leave notes on an HTML page again; anonymous share guests still cannot.
- The floating sidebar paints above the reference/snapshot banners; the notes tab uses a sticky-note icon.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

- No new `.env` keys.
- No database migration.
