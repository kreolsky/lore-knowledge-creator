# Lore v0.32.7 — 2026-11-05

## v0.32.7

### What changed

- An audio file is accepted when its content is audio, even if the extension does not match. A `.opus` file that is really WebM now uploads and transcribes instead of being refused. A file whose content is not audio is still refused.
- Every refused request is logged by the backend with its method, path, status and reason; search for `Request refused`. 401 and 404 are left out as routine.
- The Lore Voice app has an upload journal in Settings that you can copy, with the file name, type, size, first bytes and the server's error text.

### Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

- No new `.env` keys.
- No database migration.

## v0.32.6

### What changed

- Pages load faster: the landing page no longer downloads the editor, language parsers load on demand, and opening a document by direct link shows its text sooner.
- Clicking a tab or switching documents no longer repaints the whole page and document tree.
- The app reports page load, document switch and slow input timings to telemetry for signed-in users; anonymous landing visitors send nothing new.
- A selected image shows a frame with resize handles. A second click opens a gallery of all images in the document. Several images dropped at once land in one row.
- The image toolbar no longer has a delete button; press Backspace on a selected image.
- An `.oga` audio file now uploads and transcribes.
- The Lore Voice Android app is redesigned: one key per document, microphone and system audio capture, an upload queue with retries, and a history with swipe actions, undo and a player. Build it from `android/`.

### Upgrading


- No new `.env` keys.
- No database migration.

## v0.32.5

### What changed

- An HTML page downloads as a single `.html` file with its source verbatim, instead of pdf/docx/md that produced a broken file. A Download button sits in the page toolbar next to the source toggle.
- A voice note recorded on an open HTML page is saved instead of failing on every reload.
- Members can leave notes on an HTML page again; anonymous share guests still cannot.
- The floating sidebar paints above the reference/snapshot banners; the notes tab uses a sticky-note icon.

### Upgrading


- No new `.env` keys.
- No database migration.

## v0.32.4

### What changed

- A page just created by the agent, a pipeline or another user opens as HTML right away, with its publish control working, without a reload.
- The HTML page size limit is raised from 256 KiB to 2 MiB and applies the same way to creating, importing and agent edits. The source editor refuses an edit that would grow a page past the limit; an oversized page still opens and can be trimmed.
- When HTML page hosting is not configured on the server, the page frame says so instead of showing a generic error.
- Publishing or unpublishing a page updates the toolbar and the access panel immediately.

### Upgrading


- No new `.env` keys.
- No database migration.

## v0.32.1

### What changed

- Interactive HTML pages run their scripts again: the bundled nginx stacked the app's own security headers onto artifact responses, which blocked every inline script. Existing pages work without being recreated.
- Page PIN lock: an unlocked page stays open for a short grace window after you navigate away (admin setting, default 120 s; 0 restores the immediate re-lock).
- The unpinned sidebar opens on hover but switches tabs only on click.

### Upgrading


- No new `.env` keys.
- No database migration.

## v0.32.0

### What changed

- Page PIN lock: a page can be locked with a PIN from the access panel's privacy section. Until the PIN is entered, the page shows a lock screen and hides its tabs, its tree branch and its chats; a child page asks for its ancestor's PIN. The agent cannot read a locked page either.
- Interactive HTML pages: the agent can create an HTML page, and importing an `.html` file turns it into one. Pages render in a sandboxed frame served from a separate cookieless origin.
- The agent can judge a document from a summary before opening it, jump to a section, and fetch a single table without re-reading the whole document.
- Cmd+K with no selection inserts a link titled after the picked document.
- Chat: a reply cut off by an API error stays on screen, and a reply that has started printing is not retried from scratch.
- Smaller fixes: narrower document gutters on phones, consistent sidebar resizer.

### Upgrading


- New optional `.env` key `ARTIFACT_ORIGIN` (default empty = HTML pages are off). To enable them, set it to an `https://` origin on a **different registrable domain** from your Lore host (not a subdomain of it), route that domain to the same Lore frontend, and restart. It cannot be set from the admin settings.
- No database migration.
