# Lore v0.34

## Upgrading from 0.33 or earlier

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

Required:

- Migrates the database (v0.34.0) — back up first; a rollback past this release needs the backup.
- Reload browser tabs that were open before the upgrade; old tabs show a reload notice and stop syncing.

No new `.env` key and no compose change in 0.34.

Coming from an older minor: read its note in this folder too, and follow every migration and required step.

## What changed

### v0.34.0

- Find and Replace reach inside table cells: matches are counted, highlighted and navigated to, and Replace all edits cells too.
- Tables get a cell context menu (insert, delete, move rows and columns) in place of the toolbar. Columns have fixed widths; a new column takes the width of the one at the cursor, and a table can be fitted to the page width by its content.
- One undo history for the whole document: text, cells, table operations and Replace all undo in order.
- Notes and external links work inside table cells; cell images show on first open and share the document's image gallery.
- Drag an embedded image to move it within the document. Code blocks show their language and a copy button.
- The assistant can view an image from its sandbox workspace, and sandbox commands are time-bounded with a way to stop long runs.
- The project index document stands for the whole project: it shows the project name, downloads the project as a zip, and widget keys on it cover the whole project.
