# Lore v0.32.6 — 2026-11-05

## What changed

- Pages load faster: the landing page no longer downloads the editor, language parsers load on demand, and opening a document by direct link shows its text sooner.
- Clicking a tab or switching documents no longer repaints the whole page and document tree.
- The app reports page load, document switch and slow input timings to telemetry for signed-in users; anonymous landing visitors send nothing new.
- A selected image shows a frame with resize handles. A second click opens a gallery of all images in the document. Several images dropped at once land in one row.
- The image toolbar no longer has a delete button; press Backspace on a selected image.
- An `.oga` audio file now uploads and transcribes.
- The Lore Voice Android app is redesigned: one key per document, microphone and system audio capture, an upload queue with retries, and a history with swipe actions, undo and a player. Build it from `android/`.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

- No new `.env` keys.
- No database migration.
