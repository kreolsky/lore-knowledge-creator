# Lore v0.27.2 — 2026-10-19

## What changed

- Any file (up to 100 MB, not RAR) can be dropped on the AI chat by a member with full access: it uploads straight into their sandbox workspace and the agent is told its path. Images still go to vision. Where a file cannot be attached (the notes chat, members without full access), a message says so instead of skipping it silently.
- A chat search hit opens the chat at the matched passage and briefly highlights it; a hit on a non-open branch keeps its chat's name instead of "Untitled Chat".
- Chat search ranks by relevance alone — a chat on the open document no longer outranks a better match.
- Returning to the search panel shows the previous results and scroll without searching again; a reference opened from search results is no longer hidden behind the search overlay.
- Leaving a note whose messages are still loading no longer deletes it; an untouched new note is cancelled however you leave it.
- Reloading in dark theme no longer flashes light; the new-chat field in dark theme matches the regular chat field.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys.
- No database migration (the schema only gains an optional field, applied at startup).
