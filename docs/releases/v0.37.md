# Lore v0.37

## Upgrading from 0.36 or earlier

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

Required: nothing beyond the update above.

Optional:

- Add `chat_recall_budget` to a persona's frontmatter to turn on auto-recall for it.
- Mark rarely used MCP servers "on demand" in the admin panel.

0.37 needs no database migration, no new `.env` key and no compose change.

Coming from an older minor: read its note in this folder too, and follow every migration and required step.

## What changed

### v0.37.0

- Persona auto-recall: a persona with `chat_recall_budget` recalls your earlier conversations with it that match what you just said, during a chat's first five messages. A "Recalled" row above the message links each recalled chat; small talk never triggers it.
- Persona skill sets: document tools now live in four default skills (`main-read`, `main-edit`, `main-files`, `main-config`). A persona can preload skills by name or mask, hide or allow skills (`allow`/`deny`, deny wins), skip the defaults, or drop the base persona prompt.
- On-demand MCP servers: an admin can mark a server "on demand" — the agent sees it as one skill and mounts its tools only when it needs them.
- A group moderator is now a project root in projects owned by their group's users (share links, members, project keys).
- A tool call with malformed arguments is retried instead of ending the turn.
- Documents with links no longer crash the page in pre-2023 browsers.
