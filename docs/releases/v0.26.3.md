# Lore v0.26.3 — 2026-10-14

## v0.26.3

### What changed

- Tables: an unfocused cell renders exactly like the cell editor — collapsed links, wiki-links, bare URLs and ligatures at the table's font size — and a link in a cell navigates like one in a document. The cell font no longer grows on first click.
- Text selection is easier to see in both themes, and chat uses the same selection color as the editor.
- Dark theme: banner buttons on references and snapshots use the body-text tone.
- Right-panel tabs no longer show a 1px seam glitch.
- Chat on touch devices: the context-usage and cache-hit meters are hidden so the input row fits a phone screen; desktop is unchanged.
- Notes: the voice-input button has the same filled backing as in chat.

### Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys.
- No database migration.

## v0.26.0

### What changed

- Search your own chats: the Search panel has a "Chats" mode that finds your chats in the project by meaning, with chats of the open document's subtree ranked first (or, with "In this document", only those). A hit opens the chat beside the document and scrolls to the message.
- Chat title search moved from the new-chat header into the Search panel's "Chats" mode; title matches appear instantly above the meaning-based hits.
- The assistant can recall what you said in your other chats of the project (`search_my_chats`). It never sees other people's chats, notes, other projects or the current conversation; deleted or edited-away text drops out at once. Ships as the `chat-recall` skill, which an admin can disable.
- "Don't index this chat": a checkbox when starting a chat, a toggle in the chat header and a mark in the chat list keep a conversation (with all its branches) out of chat search.
- Editor: a quick double-click on a link opens it instead of selecting a word.
- Dark theme: calmer body text with brighter bold and headings, a distinct background for code blocks, warmer own-message bubbles, and dark native checkboxes.

### Upgrading


`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys. Chat search uses the embeddings you already configured; after the upgrade the worker indexes existing chats in the background.
- No database migration (the schema only gains a new table and field).
