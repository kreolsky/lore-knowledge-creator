# Lore v0.21.1 — 2026-10-02

## What changed

- **Deleting a project is instant.** Only the project itself is marked deleted; its documents, references and chats keep their own state, and they no longer appear anywhere — public share links answer 404, widget keys answer 410, embeddings and admin pages skip them.
- **Large projects: `ref:` links work past the 1000th reference.** Links no longer render as broken, a click opens the reference instead of "not found", and the `ref:` suggestions search titles on the server.
- **A reference's hover preview shows its latest saved body**, not the one from when the tab was opened.
- **Admin panel → Info** shows how big the database is on disk and how much data is marked deleted, table by table. The collapsed project card shows the owner's name again.
- **More resilient database connection.** The backend recovers on its own when its connection to SurrealDB drops, instead of failing requests until a restart.
- **Fewer settings.** Seven purely internal tuning knobs are no longer shown in the admin panel. Upload size limits have built-in defaults (audio 500 MB, images and Markdown 50 MB) and no longer need to be set.

## Upgrading

The compose file changed (the backend now mounts the database volume read-only for the Info page), so download it again:

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source. Without the flag `pull` reports *pull access denied* for `lore-harness`, `lore-sandbox` and `lore-sandbox-gw` — harmless, the update still works.

- `MAX_AUDIO_SIZE_MB`, `MAX_IMAGE_SIZE_MB` and `MAX_MARKDOWN_SIZE_MB` can be removed from your `.env`; if present they still override the defaults.
- No database migration.
