# Lore v0.32.3 — 2026-11-03

## What changed

- A shared HTML page (dashboard) opens without side panels; a single-page share shows only the header.
- A page declaring `<meta name="color-scheme" content="dark|light">` is shown in that theme; the viewer's own theme is restored on leaving it.
- The share dialog no longer offers subtree or comments for an HTML page, and notes cannot be added to HTML documents.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

- No new `.env` keys.
- No database migration.
