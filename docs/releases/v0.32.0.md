# Lore v0.32.0 — 2026-11-02

## What changed

- Page PIN lock: a page can be locked with a PIN from the access panel's privacy section. Until the PIN is entered, the page shows a lock screen and hides its tabs, its tree branch and its chats; a child page asks for its ancestor's PIN. The agent cannot read a locked page either.
- Interactive HTML pages: the agent can create an HTML page, and importing an `.html` file turns it into one. Pages render in a sandboxed frame served from a separate cookieless origin.
- The agent can judge a document from a summary before opening it, jump to a section, and fetch a single table without re-reading the whole document.
- Cmd+K with no selection inserts a link titled after the picked document.
- Chat: a reply cut off by an API error stays on screen, and a reply that has started printing is not retried from scratch.
- Smaller fixes: narrower document gutters on phones, consistent sidebar resizer.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

- New optional `.env` key `ARTIFACT_ORIGIN` (default empty = HTML pages are off). To enable them, set it to an `https://` origin on a **different registrable domain** from your Lore host (not a subdomain of it), route that domain to the same Lore frontend, and restart. It cannot be set from the admin settings.
- No database migration.
