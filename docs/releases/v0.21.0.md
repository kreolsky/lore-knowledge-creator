# Lore v0.21.0 — 2026-10-01

## What changed

- **Install with one file, no `.env`.** Download `docker-compose.yml`, run `docker compose up -d`, sign in as the preset admin, and set the AI API URL, key and models in Admin panel → Models & APIs. Everything — the agent, embeddings, speech recognition, session titles, web search — works from the next message, with no restart. The database password and the agent's internal secret are generated on first start and kept in the `secrets` volume.
- **The admin panel shows only what you configure.** The Infrastructure section is gone. The session cookie is marked Secure automatically when the browser comes over HTTPS (your proxy must send `X-Forwarded-Proto`, see [self-hosting](../self-hosting.md)). The running version is shown in the header: "Admin panel (v0.21.0) : …".
- **Settings are grouped where you look for them:** Models & APIs → Search → Tools → Agent → Storage. Web search now lives in the Search tab, next to retrieval and query rewrite. STT and ComfyUI concurrency sit with their services.
- **A safer agent sandbox.** Its network boundary moved into a separate `sandbox-gw` container that the sandbox cannot change, even as root. The sandbox's SSH key is generated on first start.
- **Chat:** a message sent while the agent is answering waits in a queue and goes out when the turn ends; reloading mid-answer keeps the text already shown; with no models available the chat says so instead of offering an input that cannot send.
- **Projects:** a built-in "Lore guide" section in every project that the agent reads when asked how Lore works; project descriptions; manual ordering of references; a title on every preview popup.

## Upgrading

The compose file changed (new `secrets-init` and `sandbox-gw` services), so download it again:

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source. Without the flag `pull` reports *pull access denied* for `lore-harness`, `lore-sandbox` and `lore-sandbox-gw` — harmless, the update still works.

`--build` is required: the agent and its sandbox are built from source.

- Requires Docker Engine 26.0+ and Docker Compose v2.26.0+.
- The settings below were removed and are ignored if still in your `.env`: `COOKIE_SECURE` (now automatic), `LORE_SECRET_KEY`, `HARNESS_DRIVER_SECRET`, `HARNESS_MODEL`, `SURREAL_*`, `TURN_TIMEOUT_S` (use `TURN_PROGRESS_GRACE_S`). If you had set `LORE_SECRET_KEY`, everyone is signed out once after the upgrade.
- If you set AI settings in `.env`, they still work as defaults; a value set in the admin panel wins.
- This release migrates the database — back up first; a rollback past this release needs the backup.
