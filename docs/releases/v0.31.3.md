# Lore v0.31.3 — 2026-10-31

## What changed

- A chat image the assistant shows appears in its tool plate only; the reply names it in words instead of embedding it. The in-reply `![alt](ref:ID)` rendering from v0.31.2 is removed — it covered the chat or failed for non-reference links.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

- No new or removed `.env` keys.
- No database migration.
