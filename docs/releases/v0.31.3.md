# Lore v0.31.3 — 2026-10-31

## v0.31.3

### What changed

- A chat image the assistant shows appears in its tool plate only; the reply names it in words instead of embedding it. The in-reply `![alt](ref:ID)` rendering from v0.31.2 is removed — it covered the chat or failed for non-reference links.

### Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

- No new or removed `.env` keys.
- No database migration.

## v0.31.2

### What changed

- **Chat images**: the assistant can look at an image from this chat or another chat it can see; its tool plate shows the thumbnail and the source chat's title. Any chat image (not only the latest) can be saved as a reference. The assistant now opens an image before describing or saving it.
- Chat replies render `![alt](ref:ID)` as the reference's image.
- **Hide a subtree's chats from the list**: a new Access-tab option hides the chats of a document's subtree from the chat list while you are outside that subtree. It can only be on together with hiding them from search.
- Fixed: a chat image placed only inside a table cell showed as a raw link.
- Fixed: a page translated by the browser's auto-translate no longer crashes into the error screen.
- SurrealDB upgraded to v3.3.5.

### Upgrading


- No new or removed `.env` keys.
- No database migration (one additive field). The SurrealDB image changes to v3.3.5 — back up the database first.

## v0.31.1

### What changed

- **Copy an image**: Cmd/Ctrl+C on a selected image puts the picture itself on the clipboard along with its markdown link. Pasting into Google Docs, a messenger or a design tool inserts the image; pasting inside Lore inserts the link. Copying an image needs HTTPS (or localhost) — otherwise an error is shown and only the link is copied.

### Upgrading


- No new or removed `.env` keys.
- No database migration.

## v0.31.0

### What changed

- **Images in documents**: drop an image file where you want it, drag a chat-generated image or a reference from the panel into the document; a selected image gets a toolbar and corner/edge resize handles with a live size field. Images in table cells behave the same.
- Tables and images are solid blocks: a guarded anchor, stable column widths, consistent Enter/Esc.
- The left panel can be unpinned to auto-hide over the editor.
- The chat content picker always lists the open document's own references, even in large projects.

### Upgrading


- No new or removed `.env` keys.
- No database migration.
