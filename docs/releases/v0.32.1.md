# Lore v0.32.1 — 2026-11-03

## What changed

- Interactive HTML pages run their scripts again: the bundled nginx stacked the app's own security headers onto artifact responses, which blocked every inline script. Existing pages work without being recreated.
- Page PIN lock: an unlocked page stays open for a short grace window after you navigate away (admin setting, default 120 s; 0 restores the immediate re-lock).
- The unpinned sidebar opens on hover but switches tabs only on click.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

- No new `.env` keys.
- No database migration.
