# Lore v0.31.2 — 2026-10-31

## What changed

- **Chat images**: the assistant can look at an image from this chat or another chat it can see; its tool plate shows the thumbnail and the source chat's title. Any chat image (not only the latest) can be saved as a reference. The assistant now opens an image before describing or saving it.
- Chat replies render `![alt](ref:ID)` as the reference's image.
- **Hide a subtree's chats from the list**: a new Access-tab option hides the chats of a document's subtree from the chat list while you are outside that subtree. It can only be on together with hiding them from search.
- Fixed: a chat image placed only inside a table cell showed as a raw link.
- Fixed: a page translated by the browser's auto-translate no longer crashes into the error screen.
- SurrealDB upgraded to v3.3.5.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

- No new or removed `.env` keys.
- No database migration (one additive field). The SurrealDB image changes to v3.3.5 — back up the database first.
