# Lore v0.21.2 — 2026-10-05

## What changed

- **The agent's system prompt is editable** in Admin → Agent, with Save and Reset. The next turn in every project uses the new text; Reset restores the shipped default. The text must keep the `{embed_schemes}` token exactly once. The Agent tab now comes before Tools.
- **Embedding calibration sits next to the embedding model**: Models → Embedding calibration holds the query instruction, the retrieval score floor, the duplicate-fact similarity and the merge-candidate floor.
- **Eleven search, indexing and memory limits are editable live** — embedding timeout, chunk size and input ceiling; memory facts and chunks per search; token budgets for documents, references and memory; project-memory merge candidates and budgets. Each setting explains what it does, which way to turn it and when it takes effect.
- **The "Query rewrite" section in Admin → Search is gone.** It never affected results; search behaves exactly as before.
- ComfyUI and MCP gateway settings are reordered and described in plain language.
- The README links the companion LLM API Gateway and STT API Server, and `scripts/search-tuning/` lets you re-derive the score floor and drop-off after switching embedding models.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source. Without the flag `pull` reports *pull access denied* for `lore-harness`, `lore-sandbox` and `lore-sandbox-gw` — harmless, the update still works.

All three lines are needed, as in the README → Update: skipping a release means skipping its compose file too, and an install older than v0.21.0 does not start on these images without the new one.

- No new `.env` keys; new settings default to the previous built-in values.
- No database migration.
