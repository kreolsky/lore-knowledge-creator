# Lore v0.25.1 — 2026-10-08

## What changed

- Generated images can be downloaded and deleted from the chat image preview; a downloaded image is named after its document. Deleting needs full access.
- Deleting the picture of a reference that has no text deletes the reference itself, and the image viewer moves on to the neighbouring image.
- Starting a new chat while another one is still answering sends right away; the other chat keeps running and shows its stream and Stop button when you return.
- Returning to a chat right after sending no longer hides the Stop button until the answer ends.
- A turn waiting on a subagent is no longer cut off by the silence timeout while the subagent is working.
- The agent can read web pages with `web_fetch` (public addresses only). Deep research runs only when asked for by name, starts with a plan to approve and saves its findings as references.
- Image file buttons on a reference stay in view while a tall picture scrolls.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys.
- No database migration.
