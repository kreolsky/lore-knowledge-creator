# Lore v0.24.2 — 2026-10-06

## What changed

- An agent chat whose turn ended just before a connection drop no longer stays stuck on an open turn until a page reload; the close is re-sent when the connection resyncs.
- A message restored after a failed send is appended to the draft the same way whether it came from the queue or a manual send.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

Old images are not removed by an update; reclaim disk space with `docker image prune -a` once the new release is healthy.

- No new `.env` keys.
- No database migration.
