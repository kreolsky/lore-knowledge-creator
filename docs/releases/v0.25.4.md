# Lore v0.25.4 — 2026-10-12

## What changed

- A message sent while the agent is busy now queues as a chip with ✕ above the composer: it runs as its own turn after the ones before it, survives a page reload and shows in every tab. Images queue too.
- ✕ on a chip removes the message from the queue; Stop hands queued messages (text and images) back to the composer, and works on a turn started in another tab.
- Two quick sends in a row no longer fail the turn or lose its content; two first turns in a fresh project no longer fail with "Agent setup failed".
- The new-chat button shows a back arrow and doubles as the way back to the chat list.
- Admins can hide a model from every chat picker (Admin → Models: Hidden · Private · Public). A hidden model still serves technical calls (prompt refinement, titles, extractor) and sessions pinned to it; the default chat model cannot be hidden. Models & APIs and Model access now sit right after Info.
- A deleted document in a project's Skills folder no longer turns off the shipped skill of the same name.
- Inline code in a heading scales with the heading.
- The user guide is now in English.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys. `TURN_LOCK_*` keys, if you set any, are no longer read.
- Browser tabs open before the upgrade must be reloaded before sending chat messages.
- No database migration.
