# Lore v0.24

## Upgrading from 0.23 or earlier

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

Required:

- The new `docker-compose.yml` is required: it adds the `harness-attachments` volume.
- If you serve Lore from an origin other than the host the browser connects to, list it in `CORS_ORIGINS`, otherwise WebSockets from it are refused.

Optional:

- Review extractor configs that use multiselect variables if you relied on the "and" before the last item.
- Old images are not removed by an update; reclaim disk space with `docker image prune -a` once the new release is healthy.

No new `.env` keys, no database migration in 0.24: the schema change is additive and applied on start.

Coming from an older minor: read its note in this folder too, and follow every migration and required step.

## What changed

### v0.24.3

- Sign-in throttling is per account (10 attempts / 15 min); a browser that has signed in before gets a device cookie and its own budget, so someone guessing at your email no longer locks you out.
- A page on a foreign origin can no longer open a project or collab WebSocket with your session cookie.
- Changing your password or email signs out every other device.
- The sign-in form distinguishes a wrong password, too many attempts, and a server or network failure.
- Notes and references that arrive from outside (a widget key or an MCP key) are marked unread for the key owner: highlighted in the document, its tabs and the tree, cleared on open. Per-document arrival toggles live in the access panel.
- The widget can post notes (`POST /api/widget/note`) and upload any supported file type, not only audio.
- A new chat with a short first message no longer gets a title ending in "[chat started"; a title produced after the turn ended still renames the chat.

### v0.24.2

- An agent chat whose turn ended just before a connection drop no longer stays stuck on an open turn until a page reload; the close is re-sent when the connection resyncs.
- A message restored after a failed send is appended to the draft the same way whether it came from the queue or a manual send.

### v0.24.1

- **Chat images survive an update.** The agent's attachment store was not a volume, so every container recreate deleted it and any chat that ever carried an image failed with *Attachment object is missing*. It now has its own volume. Chats already broken this way stay broken — rewind them (next bullet).
- **Rewind an agent chat to before a user message.** Hide a message and everything below it, then send a new one (with fresh attachments) as a sibling branch. Nothing is deleted; the branch switcher offers both.
- Messages queued while the agent is answering are no longer lost when the turn ends; a failed send puts its text back into its chat.
- A model-gateway refusal (401/403) now says what to check (the AI API key and its allowed endpoints in Admin → Models & APIs), and the harness log carries the gateway's reason.
- A reasoning model works as the chat-title model.
- Public share: every node of `GET /api/public/documents/{id}/tree` carries `created_at` and `updated_at` (ISO-8601), so a site built from a shared subtree can sort and date posts.
- An install upgraded from before v0.21.0 without the new compose file now fails at startup at once with a message saying how to fix it, instead of retrying for a minute.

### v0.24.0

- **Extractor: `ranges` tables bound to a variable.** A table named after a variable (or a `calculate:` output) whose rows carry attributes produces `<var>_<attr>` template variables — `min`/`max` for numbers, `is: [..]` for enum values, `by:` for per-selector sub-tables. No `calculate:` line is needed; `range()` works as before.
- A malformed bound table now fails the extractor run at setup, and the reason appears in the Pipeline Error note on the source document instead of leaving the marks empty.
- **Multiselect values now join with ", " by default** — "A, B and C" becomes "A, B, C". Set `separator: " and "` on the variable to get the old wording.
- **Phones and tablets:** hover previews no longer open on a tap, row menus open on tap and close on a tap outside, hover-only actions are always visible on touch, inputs no longer trigger iOS zoom, and the chat send button is an icon-only square on narrow screens.
- An additive schema update no longer logs a schema-fingerprint mismatch at ERROR on every startup.
