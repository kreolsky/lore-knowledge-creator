# Lore v0.31.0 — 2026-10-29

## What changed

- **Images in documents**: drop an image file where you want it, drag a chat-generated image or a reference from the panel into the document; a selected image gets a toolbar and corner/edge resize handles with a live size field. Images in table cells behave the same.
- Tables and images are solid blocks: a guarded anchor, stable column widths, consistent Enter/Esc.
- The left panel can be unpinned to auto-hide over the editor.
- The chat content picker always lists the open document's own references, even in large projects.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

- No new or removed `.env` keys.
- No database migration.
