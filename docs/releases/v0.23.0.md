# Lore v0.23.0 — 2026-10-05

## What changed

- **Models are private unless granted.** A non-admin user can run the default chat model plus the models an admin granted to Public, to their moderator's group, or to an admin group they belong to. A turn on any other model is refused, and the model picker lists only what the user may run.
- **New admin sections: Model access and Groups.** Grant each model to Public, moderator groups or admin groups; create, rename, delete and fill admin groups. Moderator groups are listed read-only.
- A chat turn on a model you are not granted names the model, refreshes the list and opens the picker; the pinned model shows as "(not available)".
- Admin → Info caches storage statistics for 30 minutes and shows when they were measured; Refresh measures again.
- The admin sidebar is reordered: Info, Users, Groups, Model access, Projects.
- The table of contents in the left panel scrolls again.
- On phones, the document-tree drawer now mirrors the desktop left side.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source. Without the flag `pull` reports *pull access denied* for `lore-harness`, `lore-sandbox` and `lore-sandbox-gw` — harmless, the update still works.

All three lines are needed, as in the README → Update: skipping a release means skipping its compose file too, and an install older than v0.21.0 does not start on these images without the new one.

- No new `.env` keys.
- No database migration (three new tables are created on startup).
- **After upgrading, grant models in Admin → Model access.** Until you do, non-admin users can only use the default chat model (`CHAT_MODEL`).
