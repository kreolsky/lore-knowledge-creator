# Lore v0.28.2 — 2026-10-21

## v0.28.2

### What changed

- A guest on a public link with comments enabled sees a member's new note in under a second. The guest page no longer polls for notes every 5 seconds; it keeps one WebSocket per open document that only signals "changed".
- Revoking a share, deleting or moving the document, or deleting the project closes the guest's socket, and the guest page shows the lost connection instead of silently going stale.
- An empty notes list on a public page no longer flashes the loader.
- Escape cancels a guest's unsent note from the name field too.
- Selecting text with a double or triple click opens the note button again.

### Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys. If you run your own reverse proxy in front of Lore, make sure it forwards WebSocket upgrades for every path under `/ws/` (the new socket is `/ws/public/doc/{id}`).
- No database migration.

## v0.28.0

### What changed

- Notes are now a layer over the document instead of links in the text: a note anchors to its fragment with CRDT relative positions, so the highlight moves with the text as the document is edited and survives wholesale rewrites (checkpoint restore, file re-upload, transcription import). Deleting the fragment turns the note into an orphan that stays listed with its quote instead of silently breaking; undo does not revive it.
- Comments on public links: the owner can turn comments on for a share link, and anyone holding it selects text and leaves a note under a guest name. A guest's note follows the text while a member edits the document; guests can delete their own single-message note, and a guest message is capped at 2000 characters.
- Long note threads load newest-first with a load-older button; the note's title shows in the pill meta row; hovering a highlighted fragment shows the note again.
- The AI chat gains an "up" button above scroll-to-bottom that steps through your own previous messages, skipping assistant rows.
- The dashboard badges only restricted access (comment-only / read-only); a fully shared project reads like your own.

### Upgrading


`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys.
- This release migrates the database — back up first: in-text note links are converted into anchored notes (the link syntax is removed, the label text stays) and the retired anchor offset columns are dropped. A rollback past this release needs the backup.
