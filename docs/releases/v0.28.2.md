# Lore v0.28.2 — 2026-10-21

## What changed

- A guest on a public link with comments enabled sees a member's new note in under a second. The guest page no longer polls for notes every 5 seconds; it keeps one WebSocket per open document that only signals "changed".
- Revoking a share, deleting or moving the document, or deleting the project closes the guest's socket, and the guest page shows the lost connection instead of silently going stale.
- An empty notes list on a public page no longer flashes the loader.
- Escape cancels a guest's unsent note from the name field too.
- Selecting text with a double or triple click opens the note button again.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys. If you run your own reverse proxy in front of Lore, make sure it forwards WebSocket upgrades for every path under `/ws/` (the new socket is `/ws/public/doc/{id}`).
- No database migration.
