# Lore v0.27

## Upgrading from 0.26 or earlier

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

No new `.env` keys, no database migration in 0.27: the schema only gains an optional field, applied at startup.

Coming from an older minor: read its note in this folder too, and follow every migration and required step.

## What changed

### v0.27.2

- Any file (up to 100 MB, not RAR) can be dropped on the AI chat by a member with full access: it uploads straight into their sandbox workspace and the agent is told its path. Images still go to vision. Where a file cannot be attached (the notes chat, members without full access), a message says so instead of skipping it silently.
- A chat search hit opens the chat at the matched passage and briefly highlights it; a hit on a non-open branch keeps its chat's name instead of "Untitled Chat".
- Chat search ranks by relevance alone — a chat on the open document no longer outranks a better match.
- Returning to the search panel shows the previous results and scroll without searching again; a reference opened from search results is no longer hidden behind the search overlay.
- Leaving a note whose messages are still loading no longer deletes it; an untouched new note is cancelled however you leave it.
- Reloading in dark theme no longer flashes light; the new-chat field in dark theme matches the regular chat field.

### v0.27.1

- A reference's chat can be moved to any document: while the reference is open, its chat header shows the change-parent icon; picking a document (or project level) moves the chat there as a plain document chat. No chat can be moved onto a reference.
- The documents attached to a chat as context are listed without numbers.
- The user guide explains how to connect an external agent with an agent key (the `/mcp` address, the token, a Claude Code command and a bare JSON-RPC call) and how to send a note with a widget key (`POST /api/widget/note`). The search page intro mentions the Chats mode.
- Each release now appears on the repository's Releases page.

### v0.27.0

- **Theme digest**: a new pipeline kind. A digest bound to a theme document writes one report per run about what is new since the previous report — voice notes attached to the theme document, members' chats on it, and their other chats that match the theme. It runs on demand ("Run now"), after a transcription on the theme document finishes, or on a schedule. A member's digest reads only their own chats; a project owner may include other members. Only the digest's author or a project owner may change, run or schedule it.
- Pipeline cards save themselves once a config and target documents are chosen; the Save button is gone. The references panel entry is now "Pipelines".
- A transcription stuck in "queued" can be retried.
- Extractor errors name the model and the provider's reason instead of a bare HTTP status.
- Model access has a new **Tools** tier: the model appears in every user's utility pickers (the extractor model) but not in the chat picker. "Hidden" now means "in no picker". The extractor model picker lists only models that support structured outputs.
- An unindexed chat is marked in amber in the chat header and the chat list.
- Row actions: passing the cursor over the menu button no longer opens the menu.
- The built-in user guide is updated for recent releases.
