# Lore v0.29.1 — 2026-10-24

## What changed

- Account capability tiers: every user has a tier — `base` (documents only), `voice` (+ speech-to-text) or `ai` (+ chat, extractors, schedules, image generation). Admins and moderators set it when creating or inviting a user and in the user edit panel. The server enforces it on every costly start in any project; the UI hides what the tier does not allow and explains a refusal. Admins always have every capability. Existing users are upgraded to `ai`, so nobody loses a feature.
- Admin → Model access: drag models to order them; the chat and utility model pickers follow that order.
- Chat: prompt rail ticks render evenly at any browser zoom and preview the jump target on hover; a failure inside the response stream now shows a warning instead of being swallowed.
- Recording: a recording-cache failure during a take shows one warning; the take still uploads.
- Notes: the note connector follows its anchor while you type above it.
- Mobile: swiping the document tree or the references list scrolls instead of starting a drag-reorder.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new or removed `.env` keys.
- This release migrates the database (adds the user tier and backfills `ai` for existing users) — back up first, a rollback past this release needs the backup.
