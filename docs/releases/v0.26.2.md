# Lore v0.26.2 — 2026-10-13

## What changed

- Admin: the Embeddings tab shows the chat-recall index — chunks indexed, messages waiting to be indexed, chunks waiting for purge — and says why indexing is off (skill disabled or embeddings not configured) instead of showing a 0 that reads as "all indexed".
- Admin: "Index chats now" queues the same work the hourly sweep does, so after changing `EMBEDDING_MODEL` the re-index can be started right away and watched.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source.

- No new `.env` keys.
- No database migration.
