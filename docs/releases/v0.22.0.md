# Lore v0.22.0 — 2026-10-05

## What changed

- **Compact layout for phones and portrait tablets.** A project opens on the center area only. A header button slides the document tree in as a drawer; a second button opens the right panel full screen. At most one is open at a time, and opening a document in the center closes it.
- Using Lore on a phone no longer changes your saved desktop layout.
- On a compact screen a reference always opens in the center.
- The chat input stays above the on-screen keyboard.
- The chat header's "Chats" button is now "+ New chat".
- The README recommends the LLM API Gateway as the way to connect local models.

## Upgrading

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

`--ignore-buildable` skips the agent and sandbox images in `pull`: they are not published, `up --build` builds them from source. Without the flag `pull` reports *pull access denied* for `lore-harness`, `lore-sandbox` and `lore-sandbox-gw` — harmless, the update still works.

All three lines are needed, as in the README → Update: skipping a release means skipping its compose file too, and an install older than v0.21.0 does not start on these images without the new one.

- No new `.env` keys.
- No database migration.
