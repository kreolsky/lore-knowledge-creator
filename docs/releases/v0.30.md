# Lore v0.30

## Upgrading from 0.29 or earlier

```sh
curl -O https://raw.githubusercontent.com/kreolsky/lore-knowledge-creator/main/docker-compose.yml
docker compose pull --ignore-buildable
docker compose up -d --build
```

Required:

- Migrates the database (v0.30.0) — back up first; a rollback past this release needs the backup.
- If you never set `LORE_PORT`, Lore now listens on `5673` instead of `8080`. To keep the old port, add `LORE_PORT=8080` to `.env` (or `127.0.0.1:8080` behind a proxy); otherwise update your reverse proxy to `127.0.0.1:5673`.

Optional:

- Link previews work only if your reverse proxy passes the original `User-Agent` and `Host` headers (most do by default) and sets `X-Forwarded-Proto` when it terminates TLS.

No other new or removed `.env` keys in 0.30.

Coming from an older minor: read its note in this folder too, and follow every migration and required step.

## What changed

### v0.30.4

- **Download a document subtree as a Markdown zip from the browser** — a `*.zip` item in the snapshot tab's download menu. A parent's content is now `README.md` in the zip (was `INDEX.md`); import still accepts both.
- Tables in the editor: link clicks navigate, clicks land on the pressed cell, Cmd/Ctrl+click opens links, indented tables lose the empty first column.
- Chat: voice input lands at the caret; discarding a queued message returns its text to the composer; Clarify no longer adds an intro line.
- New help page on connecting an external agent over MCP.

### v0.30.3

- **Markdown export and import of a document subtree over MCP.** An agent can export a subtree as a zip of Markdown files (images and in-subtree links included) and import such a folder back as a subtree; GFM tables become table blocks.
- MCP gateway hardening: a per-IP request ceiling, download tokens bound to their purpose, a narrower CSRF exemption.

### v0.30.2

- **Link previews look like article cards.** A published document's link now shows the document's first image (an image inside the published pages, or an external image it embeds) instead of the generic Lore image, when it has one.
- The preview text is the article's opening: a YAML front-matter block, a first heading that repeats the title, and image captions are left out.

### v0.30.1

- **Link previews for published documents.** A published document's link pasted into Telegram, WhatsApp, Slack, Discord, VK and similar apps now unfolds into a card with the document's title, a short excerpt and the Lore image. A link to a document that is not published shows a generic Lore card and reveals nothing about the document.
- **Running chats are marked.** A chat where the assistant is working right now carries a live mark in the chat list.
- The "hidden from chat search" mark is now a green shield instead of a mask.
- **SurrealDB upgraded to v3.3.4** (was v3.3.0): fixes wrong nearest-neighbour results and an index reporting ready before it finished building.

### v0.30.0

- **Private chat rooms.** A document's Access tab can mark its subtree as private for chats: chats started inside it are not found by chat search run from outside the subtree, and stay searchable from inside. The tree marks such documents.
- **Whole-chat analysis.** The assistant can list your chats and read one whole. A new chat-header action, "Analyse in a new chat", opens a fresh chat with that request prefilled. Chat history is the in-app assistant's memory only: external agent keys (MCP clients, automation) are refused.
- **Approval cards show the change.** Before you approve a document or table edit, the card shows what is removed and added.
- **Documents no longer vanish under the project index.** A document saved under the index (including extractor and digest outputs) now lands at the project root; existing ones are moved there on upgrade.
- Read-only tables show link labels instead of raw link syntax; the chat prompt rail and the phone layout of the chat are smoother; several dark-theme fixes.
- **Default port is now 5673** (was 8080).
