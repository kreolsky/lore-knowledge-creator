# Contributing

Issues — bug reports, questions, feature ideas — are welcome.

Pull requests are not accepted yet. Lore is dual-licensed (free under the Business Source License for small studios, commercial above the thresholds in [LICENSE](LICENSE)), so contributions will need a Contributor License Agreement; until one is in place, please open an issue describing the change instead.

This repository is published as release snapshots: each commit is one release, and development happens elsewhere.
